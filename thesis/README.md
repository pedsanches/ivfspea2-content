# Theses

This directory contains long-form academic manuscripts that synthesize the
research artifacts maintained in this repository.

- `masters/`: Pedro Henrique Sanches's IVF/SPEA2 master's thesis.

Article manuscripts remain isolated under `paper/`. Canonical experimental
data, analysis code, and generated results remain in the repository-level
`data/`, `src/`, `experiments/`, and `results/` directories.
