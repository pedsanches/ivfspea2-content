# clei2026

Submission snapshot for the CLEI 2026 paper (Intelligent Systems track): *Early Population Dynamics Provide Stronger Switching Signals than Static Landscape Features for Warmup-Based Operator Switching*.

This release freezes the repository state at manuscript submission.

## Included

- `paper/clei2026/` — full manuscript source, bibliography, and IEEEtran template.
  Its `figures/` entry is a symlink to `paper/ppsn2026/figures/`: the two
  manuscripts share one figure set by design, and only the symlink is tracked.
  The directory is therefore not self-contained — unpack it alongside
  `paper/ppsn2026/`, or resolve the symlink, to get the figures.
- `paper/clei2026/build/main.pdf` — compiled PDF (camera-ready).

## Not included

Raw MATLAB `.mat` traces exceed size limits and are available on request.

## Conference

52nd Latin American Computing Conference (CLEI 2026) — Intelligent Systems Track.
IEEE Conference Proceedings format (two-column, letter size).
